# Band Novel Reader 2.2Alpha

本测试版聚焦于书库切换安全性、后台发送恢复与图书导入能力。

## 书本与传输

- 发送断点改为按书本持久化保存；完成一本书时不会清除其他书籍的未完成进度。
- 切换图书前，应用会检测活动传输，先停止后台服务并保存当前断点，再切换至目标图书，避免通知片段跨书混用。
- 恢复界面会读取当前所选书本的断点；书库可同时保留多本书的可继续进度。

## 后台活动

- 增强了后台发送的会话恢复、防重入和服务状态刷新逻辑。
- 华为设备可从“后台发送保护”进入应用启动管理与电池优化设置；仍须由用户在系统中允许后台活动并锁定任务。

## 图书导入

- 本地导入现支持 TXT、TEXT、Markdown、LOG、JSON 文本和 EPUB；EPUB 会提取章节文本导入书库。
- 网络导入保留手动 API 地址方式，并增加“搜索开源图书目录”。该入口通过 Gutendex / Project Gutenberg 的公共领域目录搜索仅提供纯文本下载的无版权文本图书。

## 界面

- 导入、书本切换与状态反馈继续沿用 Material Design 3 主题和语义化组件状态。

## 测试说明

这是预发布版本。请在长时间后台发送、切换书本以及不同 EPUB 文件上进行测试；如有问题，请附上设备型号、系统版本与复现步骤。
