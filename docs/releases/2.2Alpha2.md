# Band Novel Reader 2.2Alpha2

本测试版本继续采用 **Material Design 3** 组件与主题系统，并增加分段内容清理和应用内更新体验。

## 分段内容规则

- 在 **统一设置管理 → 分段规则** 的“统一每段最大字符数”下方新增 **内容紧凑**。开启后，应用会在重新分段前合并连续空行并清理空白行中的多余空格或制表符，降低通知中出现大段留白的概率。
- 新增 **自动删除 Emoji**。开启后，应用会在分段前检测并移除常见表情符号、变体选择符和零宽连接符，减少手环通知显示异常。两项设置均自动保存；修改后会使书库重新按新规则生成分段。

## 应用更新

- 书库首页会在启动后非阻塞地检查 GitHub 发布页；检查期间 AppBar 显示圆形加载动画，也可手动点击“检查更新”。
- 发现更新时会显示 Material Design 3 更新弹窗，并提供 **稍后** 和 **立即更新**。选择“稍后”会在本地记录该版本，避免同一版本重复打扰；点击 AppBar 的手动检查可再次查看。
- 选择“立即更新”后，会显示 APK 流式下载进度、已下载字节与百分比，并在下载完成后校验长度、大小上限和 APK 压缩包头，再打开 Android 系统安装界面。若未允许“安装未知应用”，应用会引导至对应系统授权页面，返回后可再次安装。

## 网络图书导入验证

- API 设置测试、开源目录搜索、结果列表、详情页、确认下载、下载进度、完整性校验与自动导入均继续使用 Material Design 3 组件与加载反馈。
- 实测 Gutendex 对关键词“三体”返回 0 个公共领域结果，因此无法选择或下载；该目录只列出 `copyright=false` 的公共领域文本，应用会稳定显示空结果提示。
- 使用公共领域样本“The Adventures of Sherlock Holmes”（搜索 `Sherlock` 的首项）验证了目录搜索结果、详情字段与纯文本下载地址可用；具体下载和导入由应用在用户确认后执行并显示进度与校验状态。

## 测试说明

这是预发布版本。建议重点测试紧凑空行与 Emoji 清理对完整分段预览和后台发送的影响，以及首次安装时“允许安装未知应用”权限处理。
