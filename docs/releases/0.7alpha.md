# 0.7alpha — 交互与发送稳定性修复 / Interaction and Delivery Stability Fixes

**中文**：此版本聚焦早期设备运行中发现的交互与发送路径问题。它加强错误提示、恢复逻辑和发布配置，为解决启动和通知问题提供中间稳定版本。

**English**: This build focuses on interaction and delivery-path issues found during early device use. It strengthens error feedback, recovery behavior, and release configuration, serving as an intermediate stabilization point before the startup and notification fixes.

## 主要变更 / Key changes

- 改进发送流程中的异常反馈。 / Improved exception feedback in the sending flow.
- 修正若干界面状态与持久化衔接问题。 / Corrected several UI-state and persistence handoff issues.
- 优化 release APK 的安装与校验交付。 / Improved release APK installation and verification delivery.
- 保持多书库、预览、设置和断点功能。 / Kept multi-library, preview, settings, and resume functionality.
