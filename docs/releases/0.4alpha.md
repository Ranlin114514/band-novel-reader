**中文**：此版本从单书工作流升级为多书库。用户可以导入多本 TXT 图书、选择当前发送目标，并让预览、分段和断点信息绑定到相应图书。

**English**: This build upgrades the workflow from a single book to a multi-book library. Users can import multiple TXT novels, select the active delivery target, and bind preview, segmentation, and resume state to the relevant book.

## 主要变更 / Key changes

- 新增多本 TXT 同时导入和本地书库保存。 / Added multi-file TXT import and local library persistence.
- 新增当前图书选择器。 / Added an active-book selector.
- 预览、分段和发送会话按书籍隔离。 / Isolated preview, segmentation, and sending sessions per book.
- 继续使用基于文件名的本地元数据解析。 / Continued using local file-name-based metadata parsing.
- 提供调试构建和安装压缩包。 / Provided a debug build and installation bundle.
