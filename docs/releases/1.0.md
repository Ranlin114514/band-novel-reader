**中文**：1.0 汇集核心阅读工作流的主要能力：本地与网络导入、完整分段预览、毫秒级间隔、自动保存、缓存清理和更清晰的通知测试入口。此版本是从早期原型走向完整应用能力的重要里程碑。

**English**: Version 1.0 consolidates the main reading workflow: local and network import, complete segment preview, millisecond-level intervals, automatic settings persistence, cache cleaning, and a clearer notification test entry. It is the key milestone from an early prototype to a feature-complete application.

## 主要变更 / Key changes

- 新增“本地导入 TXT”和“网络导入 API”双入口。 / Added dual import entries for local TXT and network APIs.
- 网络 API 支持纯文本以及常见 JSON 正文字段。 / Network APIs support plain text and common JSON body fields.
- 设置变更自动保存，移除手动保存按钮。 / Settings changes now auto-save; the manual save button was removed.
- 进度条具有明确填充色，百分比精确到小数点后两位。 / Progress bar has explicit fill color and percentage precision to two decimals.
- 发送间隔统一使用毫秒，范围为 100–3,600,000 ms。 / Delivery interval is unified in milliseconds, from 100 to 3,600,000 ms.
- 新增测试通知入口和更清晰的通知发送失败反馈。 / Added a test-notification entry and clearer notification-delivery failure feedback.
- 设置页新增临时缓存清理，不影响书库和断点。 / Settings now include temporary cache cleaning without affecting library or resume state.
