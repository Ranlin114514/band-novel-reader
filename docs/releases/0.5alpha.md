# 0.5alpha — 首个面向设备的 Release 构建 / First Device-oriented Release Build

**中文**：此版本提供首个 ARM64 release APK，减少调试构建带来的安装包体积，并配套 ZIP 与 SHA-256 清单，适合作为真实 Android 设备上的早期安装版本。

**English**: This build provides the first ARM64 release APK, reducing the footprint of debug builds and adding a ZIP bundle and SHA-256 manifest. It is the first early version intended for installation on real Android devices.

## 主要变更 / Key changes

- 新增 ARM64 release 构建流程。 / Added an ARM64 release build workflow.
- 发布 APK ZIP 包与完整性校验清单。 / Published an APK ZIP bundle and integrity-check manifest.
- 保留多书库、分段、预览和发送进度能力。 / Retained multi-library, segmentation, preview, and progress capabilities.
- 为后续应用标识和启动稳定性修复建立发布基线。 / Established a release baseline for later app-identity and startup-stability fixes.
