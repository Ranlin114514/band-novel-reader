# Band Novel Reader 2.2Alpha4

## 启动页内容推荐

- 在“统一设置管理 → 启动体验”中新增**启动页内容推荐**。可选择随机推荐，或单独选择一言 API 的动画、漫画、游戏、文学、原创、网络、其他、影视、诗词、网易云、哲学及抖机灵分类。
- 启动页会按所选分类请求内容，并在内容出处中显示当前分类；网络不可用或服务返回异常时继续使用本地兜底文案。

## 分段内容与字数设置

- 统一每段最大字符数改为 Material Design 3 滑动调节，支持 **60–250 字**连续调整，并保留手动输入框。
- 新增**内容丰富模式**。开启后会删除全部 Emoji 与逗号、顿号、冒号、分号等弱标点，并以最大字符数优先切分非末尾片段。
- 启用内容丰富模式前会显示 Material Design 3 原生风险弹窗，说明可能造成阅读节奏变化，并在三秒倒计时完成前禁用确认按钮。

## 书源下载管理

- 从已配置 API 或公共领域书源完成下载、校验和导入后，会自动打开“书源下载管理”页面。
- 管理页展示网络下载图书的名称、字符数、文件名和当前选中状态，并可从书库 AppBar 随时进入。
- 删除网络下载图书前需要二次确认；删除会同时清理该书对应的发送断点，不影响本地导入图书或在线书源。

## AI 分段总结

- 设置新增“AI 设置与模型”，支持 OpenAI 与 OpenAI 兼容 API 的名称、API Key、Base URL、聊天路径及手动模型 ID 配置。
- 可执行 AI 连通性检查并读取 API 的 `/models` 模型列表，在模型选择页面选用当前服务支持的大模型；列表不可用时仍可手动填写模型 ID。
- 支持**使用深度思考**开关，开启时请求会携带 `reasoning_effort=medium`；对于不支持该参数的模型，可在设置中关闭后继续使用。
- 内置小说压缩提示词，以情节完整性为首要目标，要求保留人物、事件、转折、线索、行动结果和因果关系；可额外填写补充提示词。
- 在完整分段预览中可选择部分片段或全选分段进行 AI 总结，设置每段目标字数与精简、平衡、丰富三档内容程度。总结过程显示当前完成数量、线性进度与停止后续总结操作，结果会在用户确认后写回书库。

## Material Design 3 交互

- 新增设置、模型选择、书源下载管理、AI 总结、风险确认及加载反馈均使用 Material Design 3 卡片、列表、分段按钮、滑动条、弹窗、圆形进度指示器与线性进度指示器。
