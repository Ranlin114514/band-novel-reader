**中文**：2.1 为正式版，集中完成 Material Design 3 视觉系统、动态配色、后台连续发送与分段状态呈现的整合优化。

**English**: Version 2.1 is the stable release, bringing together Material Design 3 styling, dynamic colors, resilient background delivery, and clearer segment status feedback.

## 主要更新 / Key updates

- 全应用统一采用 **Material Design 3** 色彩语义、组件层级与表面样式；卡片、列表、输入框、按钮、弹窗、底部面板和提示条均按统一主题渲染。 / The app now uses a unified **Material Design 3** color system, component hierarchy, and surface styling across cards, lists, inputs, buttons, dialogs, bottom sheets, and snackbars.
- 设置新增“使用系统动态配色（莫奈）”。在 Android 12 及以上的兼容设备上，启用后会采用系统壁纸与用户选定的配色；不支持时自动回退至应用默认配色。 / Settings now includes **Use system dynamic color (Monet)**. On compatible Android 12+ devices, it follows wallpaper and system-selected colors; unsupported devices automatically fall back to the app’s default scheme.
- 发送进度条改为主题驱动的原生 Material 3 线性进度指示器，并保留百分比、已发送和剩余片段信息。 / Sending progress now uses a theme-driven native Material 3 linear indicator while retaining percentage, sent, and remaining-segment information.
- 完整分段预览会在已发送片段卡片的右上角显示完成勾选；批量调整页面会同步说明当前已完成片段数量。 / Full segment preview shows a completion check at the top-right of sent segment cards, while the batch-adjustment page reflects the completed segment count.
- 后台模式继续使用可见前台服务，并增强唤醒锁、开机／应用更新后的任务恢复，以及应用重新打开时的会话恢复尝试；设置中增加电池优化入口，便于用户允许后台运行。 / Background mode continues to use a visible foreground service, with enhanced wake-lock behavior, recovery after boot or app replacement, and session recovery when the app reopens. Settings now includes a battery-optimization entry to allow background operation.

> 系统厂商的省电策略可能仍会限制后台执行。运行长篇发送任务时，请保持“小说后台发送中”系统通知可见，并在系统电池设置中允许本应用后台运行。 Device-specific battery policies may still limit background execution. For long sending tasks, keep the “小说后台发送中” foreground notification visible and allow background operation in system battery settings.
