# 0.1alpha — 初始可用原型 / Initial Working Prototype

**中文**：第一个公开保留的开发版本，验证“将小说正文按段发送为系统通知”的核心路线。此版本引入 TXT 文本读取、基础字符数分段、通知发送页面与最初的发送间隔控制。它是功能验证版，采用调试构建，体积较大，缺少后续的多书库、网络导入和稳定性防护。

**English**: The first preserved development build validates the core idea of delivering novel segments as Android notifications. It introduces TXT ingestion, basic character-limited splitting, a notification sending page, and early interval controls. It is a debug-oriented proof-of-function build and predates multi-library support, network import, and later stability safeguards.

## 主要变更 / Key changes

- 新增本地 TXT 小说导入和基础文本解码。 / Added local TXT import and basic text decoding.
- 新增按最大字符数切分小说正文的核心分段流程。 / Added core segmentation by maximum character count.
- 新增逐段 Android 本地通知发送。 / Added per-segment Android local notification delivery.
- 新增初始发送频率设置和发送任务页面。 / Added initial interval setting and sending-task page.
- 保留为历史调试 APK，仅建议用于比较和测试。 / Retained as a historical debug APK, mainly for comparison and testing.
