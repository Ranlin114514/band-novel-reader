# 0.6alpha — 应用名称与包标识 / App Name and Package Identity

**中文**：此版本将用户可见名称统一为“手环通知小说”，并将 Android 包名迁移为 `com.ritualcollapse.wristnovel`，使安装、通知权限和手环管理软件中的应用识别更加稳定。

**English**: This build standardizes the visible app name as “手环通知小说” and migrates the Android package ID to `com.ritualcollapse.wristnovel`, improving recognition during installation, notification permission handling, and wearable-companion configuration.

## 主要变更 / Key changes

- 应用显示名称更新为“手环通知小说”。 / Updated the visible application name to “手环通知小说”.
- Android namespace 和 application ID 更新为包含 `ritualcollapse` 的稳定包名。 / Updated Android namespace and application ID to a stable identifier containing `ritualcollapse`.
- 修正 Android 启动入口的包路径。 / Corrected the Android launcher activity package path.
- 发布新的 ARM64 release 安装包与校验清单。 / Published a new ARM64 release APK and checksum manifest.
