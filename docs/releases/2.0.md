**中文**：2.0 是当前最新版本。它在首次引导的通知授权步骤中加入醒目的手环同步提示卡片，明确说明 Android 手机通知权限只是第一层，用户还必须在手环／智能手表的配套管理软件中为“手环通知小说”开启“应用通知、应用提醒、通知同步或镜像”。这降低了“手机有通知、手环没有内容”的配置困惑。

**English**: Version 2.0 is the current latest release. It adds a prominent wearable-sync prompt card to the notification-permission onboarding step. The guide explicitly explains that Android notification permission is only the first layer; users must also enable app notifications, app alerts, notification sync, or mirroring for **Band Novel Reader** in the companion software for their band or smartwatch. This reduces the common “notification on phone, nothing on band” configuration confusion.

## 主要变更 / Key changes

- 首次引导新增“还需开启手环通知同步”提示卡片。 / Added a “wearable notification sync is also required” prompt card to onboarding.
- 给出通用查找路径：“设备 / 通知 / 应用通知（或应用提醒）”。 / Provides a generic navigation path: “Device / Notifications / App notifications (or App alerts)”.
- 明确区分手机 Android 通知授权与手环管理软件镜像授权。 / Clearly distinguishes Android phone notification permission from wearable-companion mirroring authorization.
- 建议先发送测试通知，分别确认手机通知栏和手环显示。 / Recommends sending a test notification to verify both the phone notification shade and wearable display.
- 设置页新增“关于”区域，显示应用版本 `2.0（2.0.0+1）` 和公开 GitHub 仓库地址。 / Added an About section in Settings showing app version `2.0 (2.0.0+1)` and the public GitHub repository URL.
- 延续 1.2 的通知图标保留、原生权限桥接、授权状态修复和互斥发送按钮。 / Carries forward 1.2's retained notification icon, native permission bridge, authorization-state fix, and exclusive sending control.
