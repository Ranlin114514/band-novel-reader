**中文**：1.2 修复真实设备上出现的 `PlatformException(invalid_icon)`。问题源于 release 资源压缩移除了仅由运行时字符串引用的 `app_icon`。该图标现被清单显式引用并在 APK 资源表中核验。同时修复了权限弹窗授权成功后异步状态查询覆盖结果、导致“下一步”仍不可用的问题。

**English**: Version 1.2 fixes the real-device `PlatformException(invalid_icon)` failure. The issue occurred because release resource shrinking removed `app_icon`, which was referenced only by a runtime string. The icon is now explicitly referenced by the manifest and verified in the APK resource table. It also fixes an authorization race where an older async state check could overwrite a successful permission result and keep Next disabled.

## 主要变更 / Key changes

- 将 `@drawable/app_icon` 作为 Android 应用清单的显式图标引用。 / Made `@drawable/app_icon` an explicit Android manifest icon reference.
- 验证最终 APK 含有可解析的 `drawable/app_icon`。 / Verified the final APK contains a resolvable `drawable/app_icon`.
- 解决通知初始化失败和 `invalid_icon` 异常。 / Resolved notification initialization failure and the `invalid_icon` exception.
- 为引导权限读取加入状态版本保护，避免旧异步结果覆盖新授权结果。 / Added state-version protection to onboarding permission reads so stale async results cannot overwrite new authorization.
- 授权成功后立即启用“下一步”。 / Enables Next immediately after successful authorization.
