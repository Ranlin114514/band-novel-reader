# Band Novel Reader 2.2

## 多书库、发送与后台连续性

- 书库可同时保存多本图书，并按书本分别保存通知发送断点；完成或清除一本书的任务不会影响其他书籍的未完成进度。
- 切换图书前会停止对应后台发送、保存断点并刷新状态，避免通知片段跨书混用。恢复时只恢复当前所选书本的可继续会话。
- 发送页面提供前台自动发送与后台持续发送两种方式、可配置发送间隔、发送进度与暂停后继续。后台持续发送使用可见系统服务通知，针对切换应用、锁屏与服务恢复加入了防重入、状态刷新和断点保护。
- 华为设备可从后台相关设置进入应用启动管理与电池优化设置，便于授权应用在后台持续运行。
- 发送分类新增独立的通知预览与阅读节奏页面，可按当前分段规则发送首段通知、估算连续阅读时间；预览不会创建发送任务或修改断点。

## 图书导入、下载与内容恢复

- 本地导入支持 TXT、TEXT、Markdown、LOG、JSON 文本和 EPUB；EPUB 会提取章节正文，无法识别的格式会提示重新选择，批量导入会保留可导入文件并说明被跳过的文件。
- 导入页面同时提供 API 导入和公共领域书源搜索。公共领域书源支持搜索、查看作者、语言、下载次数、简介与主题详情，确认后下载并自动导入。
- API 配置集中于设置中的导入分类，支持 API 地址、书名回退和可选 Authorization；可验证连通性与响应。兼容纯文本响应，以及包含 `title` / `name` 和 `content` / `text` / `body` 字段的 JSON 响应。
- 网络导入显示实时下载进度、已下载字节、总大小与百分比，可取消或在失败后重试。写入书库前会依次校验 HTTP 响应、非 HTML 内容、25 MB 安全上限、流式下载长度、严格 UTF-8 解码和有效正文，校验失败不会导入书库。
- 完成网络下载、校验与导入后自动进入书源下载管理页面。该页面可查看网络图书信息、切换当前图书，删除前会要求确认，并仅清理该书的发送断点。
- 文本恢复会将当前图书的自定义分段恢复为刚导入时保存的基础分段快照，并清除不匹配的发送断点；原始正文和其他图书保持不变。

## 阅读与分段规则

- 手环品牌预设可按所选品牌自动应用保守单段字数；关闭预设后可手动使用 Material Design 3 滑动条和输入框调整单段最大字数。
- 内容紧凑会合并连续空行并清理无效空白；Emoji 清理会移除常见表情、变体选择符和零宽连接符。规则改变后会按新规则重新生成分段。
- 内容丰富模式以尽量填满单段容量为目标，会移除全部 Emoji 和部分弱标点；开启前提供三秒倒计时的高风险确认弹窗。
- 完整分段预览支持逐段查看、批量调整，以及对已完成发送片段显示完成状态。

## AI 总结与后台任务

- AI 设置支持 OpenAI 及兼容 API 的服务名称、API Key、Base URL、聊天路径和手动模型 ID；可读取 `/models` 模型列表、选择模型、测试连通性，并可开启或关闭深度思考参数。
- 用户可以自行编辑附加提示词。内置提示词以保留人物、事件、转折、线索、行动结果、因果和时间顺序为优先目标。
- 无论选择部分分段还是全部分段，AI 都会先接收并阅读完整小说正文作为上下文；请求中会明确标出本次用户选择的分段范围，并要求仅输出当前目标段落的压缩结果，避免范围外内容被改写或混入。
- AI 总结可在应用内转入后台执行，用户可以继续浏览、导入或进入其他页面。任务完成或失败时会发送状态通知并弹出应用内提示。
- 完成后会显示所选分段的完整结果预览。用户可选择仅覆盖本次已选分段，或抛弃结果；确认覆盖前不会写入书库。应用前会验证总结期间分段是否发生变化，避免误覆盖，并清除该书不匹配的发送断点。
- API、网络、认证、模型、上下文容量、限流、响应格式或空白结果错误会显示 Material Design 3 弹窗，给出服务返回信息、原因分析和可操作的排查建议。

## 设置、主题与首次引导

- 统一设置采用八个 Material Design 3 分类：**后台、主题、阅读、发送、导入、AI、实验室、关于**；所有已有选项均保留，设置变更会自动保存。
- 后台分类包含启动体验、通知权限与后台运行相关入口；主题分类支持跟随系统、浅色、深色、Android 12 及以上动态取色，以及青绿、湛蓝、靛蓝、紫罗兰、玫粉、珊瑚、琥珀和青柠八套调色板。
- 应用统一使用 Material Design 3 原生组件、圆角卡片、加载指示器、线性进度、风险弹窗与前进淡入转场。
- 首次引导会请求通知权限、选择手环品牌并应用容量预设，随后可选择前台自动发送或后台持续发送；品牌预设、发送方式和 AI 设置均写入统一设置，之后可在对应分类继续查看和调整。AI 配置仍可跳过，稍后在 AI 分类完成。

## 启动、更新与实验室

- 启动页可选择随机内容，或固定使用一言 API 的动画、漫画、游戏、文学、原创、网络、其他、影视、诗词、网易云、哲学和抖机灵分类。网络不可用时会使用本地兜底文案。
- 应用更新支持 GitHub 官方来源与镜像来源，启动检查为非阻塞执行并保留手动检查入口。发现更新时可查看更新说明、稍后处理或立即下载；下载过程显示进度并校验长度、大小与安装包头，完成后打开系统安装界面。
- 关闭自动检查后，应用启动不会请求更新或弹窗。发现更高测试版时会先显示风险说明；选择稍后会按该版本独立记录递增启动次数间隔，手动检查始终可以重新查看更新详情。
- 实验室提供不写入书库的分段试验和更新提醒策略诊断，并在进入前显示高风险提示。

## 版本一致性与稳定性

- 关于页、更新检查标签和 Android 构建版本使用集中维护的版本元数据，降低版本信息不同步风险。
- 下载、导入、写入书库、切换图书和发送使用互斥状态管理；AI 任务对重复启动、页面离开、取消、结果过期、目标图书删除、分段变更和断点冲突实施保护，避免日常操作中的任务混乱或误覆盖。
