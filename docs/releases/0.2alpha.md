**中文**：此版本将最初的功能页面整理为更适合阅读场景的书籍主页。应用开始从 TXT 文件名推断书名、从正文生成简介，并将分段和发送选项收敛到统一设置入口。

**English**: This build reorganizes the initial functional screens into a book-oriented home page. The app begins inferring titles from TXT file names, producing a local introduction from body text, and moving segmentation and delivery options into a unified settings entry.

## 主要变更 / Key changes

- 新增书本封面式主页展示。 / Added a book-cover-oriented home presentation.
- 从文件名提取书名，并从正文生成本地简介。 / Extracted titles from file names and generated local introductions from text.
- 新增统一设置入口，集中管理分段和发送参数。 / Added a unified settings entry for segmentation and delivery parameters.
- 精简发送页面，让发送任务保持聚焦。 / Simplified the sending page to keep task controls focused.
- 保留调试 APK，功能仍处于快速迭代阶段。 / Retained as a debug APK during rapid feature iteration.
