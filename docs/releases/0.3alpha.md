# 0.3alpha — 进度可视化与发送控制 / Progress Visualization and Delivery Controls

**中文**：此版本将发送过程的状态反馈带回主页，强化“发送—暂停—继续”的可见性。用户能够查看已发送段数、剩余段数和百分比进度，为后续断点续传与交互优化打下基础。

**English**: This build returns delivery-state feedback to the home screen and improves the visibility of send, pause, and resume behavior. Users can inspect sent segments, remaining segments, and percentage progress, forming the basis for later resume and control refinements.

## 主要变更 / Key changes

- 新增主页发送进度条和数值状态。 / Added a home-screen delivery progress bar and numeric status.
- 新增暂停后继续发送的交互基础。 / Added the interaction foundation for resuming after pause.
- 改进发送任务状态文字与用户反馈。 / Improved task-state text and user feedback.
- 开始保存可恢复的发送位置。 / Began persisting resumable delivery position.
- 保留为调试 APK。 / Retained as a debug APK.
