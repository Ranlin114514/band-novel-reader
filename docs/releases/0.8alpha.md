**中文**：此版本针对书库本地数据异常时应用可能出现空白页的问题，新增启动保护界面。用户可以重试加载，或在必要时清空异常书库后继续使用应用。

**English**: This build addresses a potential blank screen when persisted library data is malformed. It adds a startup-guard screen that lets users retry loading or, when necessary, reset the problematic library and continue using the app.

## 主要变更 / Key changes

- 新增书库初始化异常捕获。 / Added library-initialization exception handling.
- 新增“重试加载”和“清空书库并继续”恢复入口。 / Added “retry loading” and “reset library and continue” recovery actions.
- 防止异常本地数据导致无内容白屏。 / Prevented malformed local data from leading to an empty blank screen.
- 发布启动保护版 ARM64 APK。 / Published a startup-guard ARM64 APK.
