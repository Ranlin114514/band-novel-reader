# Band Novel Reader 2.2Alpha5

本版将版本元数据集中管理，关于页显示、应用更新检查标签与 Android 构建版本使用同一基准，降低后续发布出现版本信息不同步的风险。

统一设置页调整为 Material Design 3 分类导航。现可快速进入“应用与后台”“主题与色彩”“阅读”“发送”“导入”“AI”“实验室”和“关于”八个区域，所有既有设置、自动保存、加载反馈、连通性测试和权限入口均继续保留。阅读区域管理分段字数、手环预设、内容紧凑、Emoji 清理和内容丰富模式；发送区域管理前后台发送、发送间隔，并提供独立的通知预览与阅读节奏页面。

主题外观新增八套 Material Design 3 调色板：青绿、湛蓝、靛蓝、紫罗兰、玫粉、珊瑚、琥珀和青柠。调色板会立即应用并自动保存；Android 12 及以上开启系统动态配色时，仍优先使用系统莫奈取色。页面统一使用 Material Design 3 原生前进淡入转场，并保留启动、卡片、状态切换和加载过程的动画反馈。

首次引导中的 AI 配置为可选步骤。用户可填写 OpenAI 或兼容 API 的服务地址与密钥，读取并选择模型、设置深度思考、测试连通性，或直接跳过并在设置中的 AI 页面稍后配置。AI 总结保留内置的情节完整性提示词，支持部分或全部片段总结。

新增实验室入口和高风险提示。实验室保留不写入书库的分段试验与更新提醒策略诊断；发送区域中的通知预览可按当前分段规则发送首段系统通知，并显示连续发送的阅读节奏估算。

应用更新支持 GitHub 官方来源和镜像来源选择。自动检查开关关闭时启动不会检查或弹窗；发现更高测试版本时会先显示风险提示。选择“稍后”后，应用按该版本独立记录递增的启动次数间隔再次提醒；手动检查始终可以重新查看更高版本的更新详情。

网络图书 API 设置现会随字段修改自动保存，仍保留实际连通性与响应测试。书库新增文本恢复操作，可将当前图书恢复到刚导入时保存的基础分段快照，清除该书不再匹配的自定义分段与发送断点，同时保留原始正文和其他图书。
