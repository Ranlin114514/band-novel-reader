# Band Novel Reader 2.2Alpha1

本预发布版本恢复从导入界面进入网络图书导入，并完善 API 与公共领域书源的完整获取和本地导入体验。

## 网络图书导入

- 从 **导入图书 → 网络导入图书** 选择 API 导入或开源书源搜索；网络导入入口不再从设置页直接启动。
- **设置 → API 导入详情** 仅保存 API 地址、书名回退和可选 Authorization；API 地址导入支持直接返回纯文本，或包含 `title` / `name` 与 `content` / `text` / `body` 字段的 JSON 响应。
- **API 导入与开源图书目录** 均提供完整流程。API 导入会在导入界面内实际连接并验证配置的 API、显示下载进度和正文预览，再由用户确认写入本地书库；开源目录额外提供搜索与结果列表。
- 下载界面显示已下载字节、总大小与百分比；未知总长度时显示已下载大小，并支持取消和失败后重试。

## 下载校验与稳定性

- 在写入书库前依次校验 HTTP 成功响应、非 HTML 文本响应、25 MB 安全上限、流式下载长度、严格 UTF-8 解码与有效正文内容；校验失败不会导入书库。
- 目录下载、写入书库、切换图书与发送操作使用互斥状态，避免并发操作造成 UI 状态冲突。
- 后台发送事件、进度保存和完成清理按书本标识隔离；迟到的旧书本回调不会改写或清除当前书本的会话。
- 应用恢复时仅恢复当前所选书本可继续的后台会话。

## 测试说明

这是预发布版本。建议重点测试网络切换、公共领域图书搜索下载、下载取消与重试、导入后立即切换图书，以及后台发送期间的恢复与切书行为。
