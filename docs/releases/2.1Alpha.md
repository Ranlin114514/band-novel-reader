**中文**：本次 2.1Alpha 测试更新聚焦启动体验、阅读分段和界面一致性。应用可在启动时从一言接口加载一句文案，网络不可用时使用本地兜底文本；用户可以在统一设置中关闭启动页，使后续启动直接进入书库。

**English**: This 2.1Alpha test update focuses on startup experience, reading segmentation, and visual consistency. The app can load a quote from the Hitokoto API at startup and falls back to local text when offline. Users can disable the startup screen in Settings to enter the library directly on later launches.

## 主要变更 / Key changes

- 新增可关闭的一言启动页，提供短超时、JSON 字段校验和本地兜底文案，不会因网络异常阻塞进入书库。 / Added an optional Hitokoto startup screen with a short timeout, JSON validation, and a local fallback so network failures never block access to the library.
- 统一设置新增“启用启动页”开关；设置自动保存，关闭后下次启动不再发起一言请求。 / Added an **Enable startup screen** toggle to unified settings. The preference is saved automatically, and disabling it prevents Hitokoto requests on future launches.
- 分段规则新增“启用预设”开关。选择手环品牌后，启用时按品牌建议的单条通知容量分段，并隐藏手动字数输入；关闭后恢复 20–1000 字的手动调节。 / Added an **Enable preset** toggle under segmentation rules. Once a wearable brand is selected, enabled presets use that brand’s recommended notification capacity and hide manual length input; disabling restores manual adjustment from 20 to 1000 characters.
- 新增系统、浅色和深色主题选择；主题偏好会自动保存。 / Added System, Light, and Dark theme selection with automatic persistence.
- 全局优化卡片、输入框、按钮、弹窗、底部面板和提示条的圆角风格，并加入轻量非线性过渡动画。 / Unified rounded styling for cards, inputs, buttons, dialogs, bottom sheets, and snackbars, with lightweight nonlinear transitions.

> 本版本为测试版。手环实际可显示内容受设备型号、固件、通知栏预览和配套管理软件影响；品牌预设是可在设置中关闭或调整的保守建议。 This is a test build. Actual wearable notification capacity varies by model, firmware, notification previews, and companion apps; brand presets are conservative recommendations that can be disabled or adjusted in Settings.
