# 版本历史 / Release History

本仓库保留完整的开发版本序列。早期构建用于历史验证，建议普通用户优先使用最新版本。为简化下载，GitHub 的每个发行页仅保留一个统一命名的安装包：`band-novel-reader.apk`。

This repository preserves the complete development-version sequence. Early builds are retained for historical verification, while most users should prefer the latest release. To simplify downloading, every GitHub Release page now retains one consistently named installer: `band-novel-reader.apk`.
