# 1.1 — 原生通知权限与互斥发送控制 / Native Notification Permission and Exclusive Controls

**中文**：1.1 引入 Android 原生通知权限桥接。首次引导会主动触发系统通知权限弹窗；未授权时无法完成引导，并可直达系统通知设置。同时主页发送控制改为互斥状态，避免“发送”和“继续”同时出现。

**English**: Version 1.1 introduces an Android-native notification-permission bridge. Onboarding actively triggers the system permission dialog; users cannot complete onboarding without authorization and can open app notification settings directly. Home-screen controls are also made mutually exclusive so Send and Resume do not appear together.

## 主要变更 / Key changes

- 新增 `MainActivity` 原生方法通道以申请 `POST_NOTIFICATIONS`。 / Added a native `MainActivity` method channel to request `POST_NOTIFICATIONS`.
- 引导页自动触发 Android 系统通知授权弹窗。 / Onboarding automatically triggers the Android system notification prompt.
- 未授权时禁用引导“下一步／完成”，并提供系统通知设置入口。 / Disabled onboarding Next/Finish until authorized and added a notification-settings shortcut.
- 主页按钮按状态互斥显示“发送”“暂停”或“继续”。 / Home button mutually displays Send, Pause, or Resume by session state.
- 保留通知自检入口，帮助定位手机与穿戴设备之间的同步问题。 / Retained notification self-test to diagnose phone-to-wearable delivery.
