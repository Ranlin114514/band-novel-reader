# 华为后台发送保护说明

华为官方支持页说明，HarmonyOS/EMUI 设备可能会因为应用启动管理、电池优化、省电模式或后台内存清理而限制应用后台运行。针对“手环通知小说”的后台连续发送，建议用户在开始长任务前完成以下操作：

1. 在多任务界面将“手环通知小说”卡片下拉并锁定。
2. 在“设置 → 应用启动管理”中关闭自动管理，并勾选允许后台活动。
3. 在“设置 → 电池优化”中将本应用设置为“不允许”优化。
4. 关闭省电模式，并在可用时启用休眠时保持网络连接。

即使应用使用前台服务和可见通知，用户从系统设置执行“强制停止”后，Android 的安全模型也不允许应用自行重新启动。应用应保存发送会话并在用户下次打开应用时恢复。
