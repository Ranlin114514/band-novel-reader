# 手环通知文本容量调研 / Wearable Notification Text-Capacity Research

## 结论边界 / Scope and limitations

手环“单条通知最大字数”通常不是一个统一的品牌级固定值。它会受到具体型号、固件、手环显示屏尺寸、手机操作系统、手机通知栏生成的原始文本长度、配套管理软件和发送应用的通知样式影响。因此，应用中的预设应理解为**保守分段建议值**，而不是保证每一型号都能完整显示的硬件规格。

A wearable brand does not have one universal, fixed maximum notification length. The limit varies by model, firmware, display size, phone OS, the source notification text generated by the phone, the companion app, and notification style. The in-app values should therefore be treated as **conservative segmentation recommendations**, not guaranteed hardware specifications for every model.

## 预设设计原则 / Preset design principles

1. 不将屏幕可见行数误当作通知总字符容量；支持滚动查看的设备可显示更多字符。
2. 预设低于公开或实测上限，预留通知标题、系统附加文字、emoji 与不同语言编码的空间。
3. 品牌选择只自动设置**分段字数**，不锁定用户设置；用户仍可在统一设置中修改 20–1000 字范围。
4. “其他品牌”不使用未知品牌的强断言；采用较保守的通用预设，并提示按实际设备显示效果调整。
